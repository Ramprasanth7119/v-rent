# Phase 1 Dashboard Competitor Research

## Executive Summary

PropertyGuru AgentNet and 99.co dominate Singapore's agent-facing PropTech UX. PropertyGuru owns 81% of property search engagement; 99.co competes on quality listings and data tools. Both platforms organize dashboards around **lead management**, **listings performance**, and **market data**. V-RENT Phase 1 should prioritize these three areas with clean information hierarchy and mobile-first design.

---

## PropertyGuru AgentNet

**Platform**: Desktop web + mobile app (latest: v2026.4.2)  
**User**: Real estate agents listed on PropertyGuru.com.sg

### Dashboard Sections

1. **Messages / Enquiries** (Primary)
   - Inbox for all incoming enquiries from PropertyGuru listings
   - New count badge prominently displayed
   - Enquiry metadata: which listing, source, lead type (buyer/seller/co-broker)
   - Quick actions: WhatsApp, call, email directly from dashboard
   - **Source**: [Managing Your Messages On AgentNet – PropertyGuru](https://www.agentofferings.propertyguru.com.my/help-centre/managing-your-messages-on-agentnet/)

2. **Lead Management Dashboard**
   - Centralized view of all PropertyGuru-sourced leads
   - **Lead Insights**: View lead profiles, preferences, activity history
   - **Behaviour-based Insights**: Preferred location, property type inferred from browsing
   - **Lead Quality Tags**: Tag/prioritize high-intent vs. cold leads
   - Filtering and labeling to organize pipeline
   - Follow-up tracking
   - **Source**: [Lead Management: Introduction to Lead Insights – PropertyGuru](https://www.agentofferings.propertyguru.com.sg/help-centre/lead-management-introduction-to-lead-insights/)

3. **Listings Management**
   - Create and edit listings directly in dashboard
   - View listing performance metrics (views, enquiries, ranking)
   - Add/manage photos and property details
   - Listing optimizer: data-driven suggestions to improve listing visibility
   - Status indicators: active, paused, sold
   - Quick actions: promote, feature, boost

4. **Ad Credits & Account**
   - Credits balance for promoted listings/featured agent slots
   - Profile picture quick access (bottom left of dashboard in app)
   - Account settings and security

5. **Tools / Additional Features**
   - **MarketWatch**: Market trends, co-broking opportunities
   - **Prospector**: Identify homeowners likely to sell (predictive lead gen)
   - **AI-Generated Videos**: Create property videos in-app
   - **Unit & Project Insights**: Pre-analyzed property highlights and price trends
   - **Featured Agent**: Booking slots for homepage prominence
   - **Promoted Listings**: Campaign creation for specific properties
   - **Source**: [AgentNet Singapore - App Store](https://apps.apple.com/sg/app/agentnet-singapore/id406066172)

### Navigation & Layout

- **Mobile-first app design** with horizontal tab navigation (Messages, Listings, Tools, Account)
- **Desktop web**: Sidebar navigation with collapsible sections
- Quick links for frequently used features
- Profile icon in corner (mobile: bottom-left) for account access
- New Tools section added to nav bar (recent update, easier MarketWatch discovery)
- **Source**: [AgentNet Singapore - Apps on Google Play](https://play.google.com/store/apps/details?id=com.allproperty.android.agentnet&hl=en_SG)

### Information Hierarchy

1. **Unread enquiries count** (top, most prominent)
2. Active listings status
3. Ad credits balance
4. Recent lead activity
5. Performance metrics (secondary)
6. Additional tools (tertiary)

### Trust & Premium Signals

- Verified Property Listings badge (trustworthiness)
- Behavior-based Lead Insights (AI-powered, sophisticated)
- Direct WhatsApp/call integration (professional communication)
- Centralized lead management (organized, professional)
- Real-time enquiry notifications (responsive UX)

### Responsive Behavior

- **Mobile app**: Touch-friendly UI with large tap targets; messages and listings accessible via tabs
- **Desktop web**: Full sidebar navigation, can manage multiple listings simultaneously
- Real-time sync between mobile and desktop

### Gaps & Notes

- Limited public UI screenshots available (authenticated platform)
- No visible performance chart/analytics dashboard in search results
- Listing optimizer specifics not detailed
- Market insights depth unclear from available info

**User**: Real estate agents creating listings and closing deals on 99.co

     - Toggle: Average Price OR Average PSF metrics

     - Toggle: Line graph OR Scatterplot visualization

   - **Project Comparison Panel**: show rental yield, TOP date, developer info when analyzing multiple properties

   - User segment: Premium plan and above agents

## Common UX Patterns Across Singapore PropTech Dashboards

### 1. **Information Architecture**
- **High priority**: Leads/enquiries, listings status, performance metrics
- **Medium priority**: Market data, tools, account settings
- **Low priority**: Help docs, settings, notifications
- **Principle**: Show revenue-driving information first

### 2. **Primary Agent Workflows**
All platforms support:
- **Listing creation/management** (faster than competitors = win)
- **Lead capture & follow-up** (centralized inbox)
- **Market analysis** (data-driven pitch to sellers/buyers)
- **Client deliverables** (reports, valuations, comparisons)

### 3. **Navigation Patterns**
- **Mobile**: bottom tab bar (Messages, Listings, Tools, Account) or top tabs
- **Desktop**: left sidebar nav + main content area
- **Quick actions**: floating buttons, inline call/email/WhatsApp
- **Breadcrumbs/back buttons** for deep hierarchies

### 4. **Data Visualization**
- **Line graphs** for trends (price, volume over time)
- **Maps** for spatial analysis (location-based leads, neighborhoods)
- **Tables** for detailed transaction data (sortable, filterable)
- **Cards** for property comparisons (side-by-side)
- **Badges/labels** for status (verified, featured, sold, pending)

### 5. **Empty States**
- Shown when: no listings, no enquiries, no data
- Design: icon + encouragement text + CTA (e.g., "Create your first listing")
- Keeps UI from feeling broken

### 6. **Loading & Error States**
- Skeleton loaders for async data (Researcher, X-Value)
- Clear error messages (e.g., "Data unavailable for this period")
- Fallback content if API fails

### 7. **Mobile-First Responsive**
- **Touch-friendly**: 44px+ tap targets
- **Readable**: 14px+ body text, high contrast
- **Scrollable**: vertical priority over horizontal
- **Bottom nav**: easier thumb reach on phones
- Avoid: horizontal scroll, small buttons, dense tables

### 8. **Trust Signals in UI**
- **Verified badges**: check icon, color
- **Data sourcing**: "Updated daily" or "Based on X transactions"
- **Certifications**: CEA (agent), REIS (real estate info), etc. if displayed
- **Professional language**: no hype, factual metrics
- **Transparent pricing**: no surprise fees on ad credits/upgrades

## Strong Patterns Worth Adopting

### 1. **Centralized Lead Inbox**
✓ Single place to see all enquiries from the agent's listings  
✓ Quick metadata: who enquired, which property, when  
✓ Direct actions: WhatsApp, call, email without leaving dashboard  
✓ Follow-up tracking: labels, priority tags, read/unread  

**Recommendation**: V-RENT Phase 1 needs an enquiry inbox by default.

### 2. **Listing Status at a Glance**
✓ Show active count, paused, sold, pending  
✓ Last updated timestamp  
✓ Quick filter by status  
✓ Visual indicators (color coded)  

**Recommendation**: Card grid or table showing top 5–10 listings on dashboard.

### 3. **Map-Based Neighborhood Context**
✓ 99.co's Researcher uses map to show data spatially  
✓ Helps agents pitch: "nearest MRT is X, schools within Y km"  
✓ Supports comparisons across neighborhoods  

**Recommendation**: Phase 1 dashboard can show a micro-map with property location + key nearby amenities (schools, MRT, hospitals).

### 4. **Performance Metrics as Cards**
✓ Key stats: views, enquiries, conversion rate (if available)  
✓ Trend indicators: ↑ (good) ↓ (needs attention)  
✓ Time period toggle: this week, this month, all-time  
✓ Non-interactive (no drill-down to Phase 1)  

**Recommendation**: 3–4 KPI cards (Views, Enquiries, Avg PSF vs Market, Availability) on dashboard header.

### 5. **Tools as Accessible Cards**
✓ Instead of deep menu, surface tools as feature cards  
✓ Each card shows: icon, title, brief description, CTA  
✓ Tools for Phase 1: PDF export, neighborhood insights, comparable analysis  

**Recommendation**: "Tools" section at bottom of dashboard; each card links to relevant feature.

### 6. **Data Export & Share**
✓ Agents want to send reports to clients  
✓ PDF export, email, share link  
✓ Signature / personal branding on reports  

**Recommendation**: Every report/analysis should have a "Share" button; PDF export for Phase 1.

### 7. **Real-Time Notifications**
✓ New enquiry badge in nav  
✓ Count of unread messages  
✓ Push notification on mobile  

**Recommendation**: Use local notifications (browser badge, tab count) for Phase 1 MVP.

### 8. **Responsive List/Table Design**
✓ On mobile: show essential columns only (property name, status, views)  
✓ Swipe to reveal actions (archive, promote, delete)  
✓ On desktop: full table with 7–10 columns, sortable headers  

**Recommendation**: Use a responsive table component; test at 400px mobile width.

## Patterns to Avoid

### 1. **Too Many Sidebar Menu Items**
✗ Overwhelming; agents want quick access to what they use daily  
✗ Deep nesting (Account > Settings > Security) wastes taps  

**Recommendation**: Limit sidebar to 5–6 primary sections; flatten hierarchy.

### 2. **Dense, Text-Heavy Dashboards**
✗ Hard to scan on mobile  
✗ Confuses priority (everything looks important)  

**Recommendation**: Use whitespace, cards, and visual hierarchy.

### 3. **Delayed Data Loading**
✗ Agents wait for enquiry counts to load (frustration)  
✗ Shows unprofessional UX  

**Recommendation**: Cache enquiry count in local storage; show immediately; refresh in background.

### 4. **Horizontal Scroll on Mobile**
✗ Tables that scroll right on phone are unusable  

**Recommendation**: Stack columns or show abbreviated mobile view.

### 5. **Missing Context**
✗ Showing "5 new enquiries" without which property or lead quality  

**Recommendation**: Always show mini-context (property name, lead type, time).

### 6. **No Empty State Design**
✗ Blank space with no guidance confuses new agents  

**Recommendation**: Design intentional empty states with encouragement.

### 7. **Relying on Red/Green Alone**
✗ Color-blind users miss status signals  

**Recommendation**: Use color + icon + text (e.g., ✓ Active, ⏸ Paused, ✕ Sold).

### Section Details

**1. Welcome & Status (Always Visible)**
- Agent name
- Last dashboard update timestamp
- Quick action: "Create New Listing"

**2. KPI Cards (Row 1 – Primary Metrics)**
- **Views**: total views across active listings this month
- **Enquiries**: new unread enquiries count (with badge)
- **Avg PSF**: average price per sqft of your listings vs. market average
- **Available**: number of available properties
- Design: card with large number, label, optional trend ↑/↓

**3. Active Listings (Row 2 – Quick View)**
- Show top 3–5 listings as cards (photo thumbnail, title, price, status badge, view count)
- Status colors: green (active), yellow (needs attention), gray (paused)
- Tap to manage; link to full listings page
- "View All Listings" CTA

**4. Recent Enquiries (Row 3 – Inbox Preview)**
- Show latest 3–5 enquiries as list items
- Each item: property name (truncated), enquirer detail (buyer/seller/agent), time, status (new/read)
- Tap to reply; link to full enquiry inbox
- Unread count badge
- "View All Enquiries" CTA

**5. Tools / Quick Actions (Row 4 – Secondary)**
- Cards for: "Export as PDF", "Neighborhood Insights", "Market Analysis" (if available)
- Icons + labels
- Non-essential for Phase 1 but useful for engagement

### Mobile Responsiveness

- **Sidebar hidden**: use hamburger menu or bottom tab nav (Messages, Listings, Tools, Account)
- **KPI cards stack vertically** (1 per row on narrow screens)
- **Listing cards wrap** (1 per row on mobile, 2–3 on tablet, 4+ on desktop)
- **Enquiry list items full-width** with essential info only (property, time, status)

### Empty States

- **No listings**: "You haven't created any listings yet. [Create Your First Listing →]"
- **No enquiries**: "No new enquiries. Keep checking!"
- **No data**: "Unable to load data. Please refresh or check your internet."

## Singapore Agent-Specific UX Requirements

### 1. **Messaging Channels**
- **WhatsApp**: primary channel (most agents + buyers use WhatsApp)
- **Phone/Call**: direct calling from dashboard
- **Email**: fallback; less common
- **SMS**: rarely used but support if possible

**Recommendation**: Lead enquiry should have "Chat on WhatsApp" button (most prominent) + Call + Email options.

### 2. **Property Classification**
- **HDB**: mandatory tenure/year built/block info (not market rate like private)
- **Private Condo**: unit, building, developer, TOP date
- **Landed/Terrace**: land size, built-up size
- **Commercial/Industrial**: zoning, lease terms

**Recommendation**: Dynamic form fields based on property type; pre-fill common fields.

### 3. **Price Display**
- **Buy/Sell**: $/sqft (PSF) is gold standard for comparison
- **Rent**: $/month, $/sqft/month
- Always show both absolute and normalized pricing
- Context: "Market average for D18 is $X PSF"

**Recommendation**: Calculate and show PSF automatically; don't make agent calculate.

### 4. **Location Context**
- **MRT/LRT**: nearest station, distance, walking time
- **Schools**: Primary (P1 registration), Secondary within 1–2 km
- **Markets/Hawker Centers**: key amenities
- **Market Districts**: CCR (Core Central Region), RCR, OCR, etc.

**Recommendation**: Use OneMap/DataMall to auto-populate on listing creation (Phase 1+).

### 5. **CEA Compliance**
- Display agent license (if public)
- Avoid false claims (e.g., "best price" unless verifiable)
- Transparent about commissions
- Respect agent privacy (no personal phone displayed in search)

**Recommendation**: Show "Licensed CEA Agent" badge with verification date.

### 6. **Local Language**
- Support Simplified Chinese, Malay, Tamil (not Phase 1, but plan for it)
- Glossary of local terms (CCR, TOP, HDB block, landed, condo, etc.)

**Recommendation**: At least interface labels in English + placeholders.

### 7. **Time Zone & Notifications**
- Agents are always on-call (evening/weekend enquiries)
- Push notifications for new enquiries (critical)
- Quiet hours option (optional)

**Recommendation**: Real-time enquiry alerts; respect user's phone settings.

### 8. **Data Freshness**
- Agents care about up-to-date market data
- "Last updated: today" or timestamp is a trust signal
- Stale data (>7 days) should be flagged

**Recommendation**: Show data timestamp; refresh button visible.
